# lazy-frames

Fully local, byte-stable video generation from a typed JSON spec. No cloud, no keys, no nondeterminism.

Same spec + same machine = byte-identical MP4, every time.

## Quick start

```bash
npm install && npm run build
node packages/cli/dist/index.js doctor
```

### Website promo

```bash
node packages/cli/dist/index.js capture https://example.com projects/acme
node packages/cli/dist/index.js snapshot projects/acme --update
node packages/cli/dist/index.js check projects/acme
node packages/cli/dist/index.js preview projects/acme
# ... approve ...
node packages/cli/dist/index.js render projects/acme
```

### Cinematic

```bash
node packages/cli/dist/index.js gen image -p projects/cine --seed 21 --style ridge --name r01
# write spec.json ...
node packages/cli/dist/index.js render projects/cine
```

## Examples

- `examples/demo` — typography + stat-hit (P0 engine proof)
- `examples/cinematic` — depth-parallax + video-layer + narration + music (P2)
- `examples/showreel` — grade + LUT + transitions + SFX + 3D + beats (P3)
- `projects/web-demo` — website capture → promo (P1, generated by `lazy capture`)

## Verify

```bash
npm run verify:demo        # P0: byte-stability (two full renders, sha256 compare)
npm run verify:cinematic   # P2: gen assets + gates + audio determinism
```

## Architecture

```
spec.json (typed JSON)
  ├─ @lazy/engine     compile spec → HTML composition + channel data
  ├─ @lazy/renderer   headless Chrome (jitless + swiftshader) → frames → ffmpeg → MP4
  ├─ @lazy/capture    site screenshots + palette/copy/font/logo extraction
  ├─ @lazy/gen-sidecar  Python: procedural music, TTS (say), SFX synthesis
  └─ @lazy/cli        lazy capture | gen | check | snapshot | render | preview | doctor
```

## Determinism

Three Chrome flags + integer-pixel rounding + putImageData for canvas scenes:
- `--jitless` (V8 interpreter — deterministic float math)
- `--use-angle=swiftshader` (software rendering — no GPU variance)
- Integer-pixel CSS transforms (no sub-pixel text rendering)
- `putImageData` for canvas-based scenes (no skia compositing nondeterminism)
