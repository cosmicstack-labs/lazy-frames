Secure by default

Lazy Frames currently accepts only reviewed registry plugins backed by built-in adapters. A repository lockfile cannot authorize itself: approval is user-local and scoped to the canonical project path. Arbitrary URLs, install scripts, lifecycle hooks, and unreviewed executable packages are rejected. Community runtimes will not be enabled until they can run with enforceable isolation and signed artifacts.
